# Working preference

- When the user authorizes a task and states acceptance criteria, keep working toward those criteria instead of ending after setup or partial progress.
- For work that spans multiple steps, continue through implementation and appropriate verification before reporting completion. Do not repeatedly end turns with partial status reports when more authorized work remains.
- If a genuine blocker prevents completion, identify the specific blocker and continue with any independent work that remains possible.
- Be explicit and accurate about what is complete; never describe partial setup as a finished migration.
